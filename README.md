# ❤️ Heart Disease Prediction System

An end-to-end Machine Learning web application that predicts whether a patient is likely to have heart disease based on medical parameters.


## 🌐 Live Demo

🔗 Streamlit App: https://heart-disease-prediction-debadrita.streamlit.app


## 📂 GitHub Repository

🔗 https://github.com/debadritaroy15-alt/heart-disease-prediction



## 📖 Project Overview

Heart disease is one of the leading causes of death worldwide. This project uses Machine Learning to predict the likelihood of heart disease using patient health information.

The application allows users to:

- Enter patient medical details
- Predict whether heart disease is detected
- View prediction confidence
- Display patient summary

---

## 📊 Dataset

**Dataset:** UCI Heart Disease Dataset

Features used:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Rest ECG
- Maximum Heart Rate
- Exercise Induced Angina
- Old Peak
- Slope
- Number of Major Vessels
- Thal

Target:

- 0 → No Heart Disease
- 1 → Heart Disease

---

## 🤖 Machine Learning Model

Algorithm Used:

- Random Forest Classifier

Accuracy:

- **83%**

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/debadritaroy15-alt/heart-disease-prediction.git
```

Go into the project folder

```bash
cd heart-disease-prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
